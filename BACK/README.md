Pasos a ejecutar

Paso 1 - instala dependencias:
### `npm install`

Paso 2 - instala nodemon: para que reinicie automáticamente el servidor cada vez que detecta un cambio en el código fuente:
### `npm install nodemon --save-dev`

Paso 3 - Ejecuta el seed.js donde ingresa la data a la Base de datos:
### `npm run seed`

Paso 4 - Corre el proyecto backend en el puerto 5000:
### `npm run dev`

Abrir [http://localhost:5000](http://localhost:5000)
